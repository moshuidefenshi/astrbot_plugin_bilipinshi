# 评屎bot

让你的bot可以吃你搬的答辩视频回复简短评价，支持 B 站卡片转换。

插件只处理包含 B 站视频链接的 QQ Json 卡片消息，不处理普通视频或普通文本链接。它只读取 B 站标题和封面进行评价，不需要 FFmpeg、yt-dlp 或其他视频处理程序。

## B 站卡片

插件会从 QQ Json 卡片中提取 BV、AV视频链接或 `b23.tv` 短链接，再请求 B 站公开接口获取标题和封面。

## 依赖

安装插件依赖即可使用。模型需要支持图像输入。

`review_tendency` 是 0 到 100 的滑块：0 偏差评，50 中立，100 偏好评。默认提示词要求 AI 只用 1 到 10 个字评价，也可以在 `system_prompt` 中修改。

仅支持 QQ 个人号 `aiocqhttp` 适配器。
